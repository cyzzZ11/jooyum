# 演示部署说明

## 一、两种演示方式

| 方式 | 适用场景 | 操作 |
| --- | --- | --- |
| **单文件 HTML（推荐）** | 拷给领导、离线演示、双击即开 | 双击根目录 **`松江区文旅态势感知平台.html`** |
| 本地服务版 | 需要局域网/投影多设备访问 | 双击 **`启动演示.cmd`**，浏览器打开 `http://127.0.0.1:4180/` |

### 单文件版说明

- 文件：`松江区文旅态势感知平台.html`（约 7.6 MB，JS/CSS/图片/街镇边界/运行时配置全部内联）
- 直接双击即可在 Chrome / Edge 打开，无需 Node.js、无需服务器、可随意拷贝
- **地图 = 天地图底图 + 街镇色块**，两者均为轻量渲染：
  - 底图：天地图矢量/注记瓦片，用普通 `<img>` 按 Web Mercator 网格拼接（需联网）
  - 色块：街镇 GeoJSON 直接投影后绘制 SVG（不依赖 Web Worker / WebGL）
  - 因此 `file://` 双击打开也能稳定看到「底图 + 区域渲染 + 街镇标注 + 图例 + 悬浮」
- **地图交互与在线版一致**（自实现，不依赖 Worker/WebGL）：
  - 拖拽平移、滚轮缩放、右上角 `+ / − / 复位` 按钮
  - 顶部「电子地图 / 影像图」底图切换（影像图对应天地图 `img_w` + `cia_w`）
  - 缩放层级 8–16 级，初始自动按辖区范围取最佳层级
- 底图瓦片若加载失败（断网），自动只保留色块图并在右下角提示
- 重新生成：`npm run build:single`（内部会调用 vite 单文件配置 + 内联脚本）

## 二、本地服务版

1. 自动检测 Node.js（需 18 及以上版本）；
2. 若 `dist/` 不存在会自动打包；
3. 启动本地服务并自动打开浏览器：`http://127.0.0.1:4180/`；
4. 演示结束后关闭命令行窗口即可。

> 为什么不能直接双击 `dist/index.html`？
> 现代浏览器禁止 `file://` 协议加载 ES Module 与 fetch 请求，直接打开会白屏。
> 项目已在 `index.html` 中内置提示页，误双击时会给出操作指引。

## 三、手动启动

```bash
# 1) 打包（首次或代码有更新时执行）
npm run build

# 2) 启动演示服务（零依赖，仅需 Node.js）
node demo-server.mjs

# 可选参数
node demo-server.mjs --port 5000     # 指定端口
node demo-server.mjs --host 0.0.0.0  # 开放局域网访问（投影/平板/其他电脑）
node demo-server.mjs --no-open       # 不自动打开浏览器
```

## 四、演示路径建议

| 顺序 | 入口 | 讲解要点 |
| --- | --- | --- |
| 1 | 文旅态势感知 → 态势总览 | 4 张指标卡：消费 13.69 亿元、游客 156.73 万人次、入境 2.35 万人次、景区 103.52 万人次；下方 4 张街镇/景区榜单 |
| 2 | 同一页切换「高频态势」 | 6 条 7 天趋势曲线（当年 vs 去年同期） |
| 3 | 旅游消费 | 消费结构（餐饮 3.91 / 住宿 4.70 …）、分类消费排行 |
| 4 | 国内旅游 / 入境旅游 / 景区游客 / 商圈游客 | 出行特征、人群画像、来源地、热门排行 |
| 5 | 对比分析 | 可自由勾选松江区与 17 个街镇横向对比（时间维度已锁定为 2026 年国庆节） |

## 五、演示态约定

- **时间**：2026 年国庆节（10 月 1 日 - 10 月 7 日，7 天），界面不显示具体日期；
- **区域**：上海市松江区；
- **锁定**：区域与时间不可修改，防止现场误操作；对比分析中的「对比区域」可自由调整；
- 如需解除锁定：编辑 `public/config/appContext.js`，把 `lockFilter` 改为 `false` 后重新打包。

## 六、打包产物说明

| 内容 | 说明 |
| --- | --- |
| `松江区文旅态势感知平台.html` | **单文件演示版**，双击即开，全部资源内联 |
| `dist/index.html` | 多文件版入口（需通过 http 访问） |
| `dist/assets/` | JS / CSS 资源 |
| `dist/config/appContext.js` | 运行时配置（接口地址、锁定开关、地图密钥等），改完刷新即可生效 |
| `dist/img/`、`dist/geo/` | 图片素材与街镇边界数据 |
| `demo-server.mjs` | 零依赖静态服务器 |
| `scripts/build-single-file.mjs` | 单文件打包脚本（`npm run build:single`） |

> 注：`lockFilter` 在应用启动时读取 `window.appContext`，修改 `dist/config/appContext.js` 后刷新页面即可生效，无需重新打包；
> 单文件版的配置已内联，需执行 `npm run build:single` 重新生成。
